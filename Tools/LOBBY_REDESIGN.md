# 로비 디자인 변경

수정 에셋은 `/Game/Lobby/wbp_lobby`와 공용 팀 행 `/Game/Lobby/wbp_lobby_slot`입니다.
기존 게임 시작, 팀 참가, 닉네임 및 팀 상태 이벤트 그래프는 유지했습니다.

## 디자인

- 롤 사용자 설정 게임 로비를 참고한 남색 배경과 금색 선/글자.
- 상단 플레이 영역과 편집 가능한 방 제목.
- 블루·레드 팀 5인 목록, 소환사 표시, 팀 참가 버튼.
- 오른쪽 협곡 이미지와 게임 정보.
- 하단 방장용 게임 시작 버튼.
- 1920×1080 디자인을 ScaleBox로 비율 유지 조절.

친구 목록, 채팅, 봇 추가 등 새로운 게임 기능은 추가하지 않았습니다.
나가기 버튼의 기존 동작 연결 상태도 유지했으며, 새로운 화면 전환 이벤트는 추가하지 않았습니다.

## 검증

- 두 에셋 재컴파일 및 저장, 에디터 에셋 검증 완료.
- 수정 전후 EventGraph 비교: UE가 재생성한 미사용 숨김 핀 GUID와 표시용 번역 메타데이터 외 동일.
- 실제 PIE 화면에서 레이아웃, 글자, 팀 슬롯 표시 확인.
- 참가 버튼 OnClicked 델리게이트를 통해 블루→레드→블루 팀 이동 및 닉네임 표시 검증.
- 게임 시작 버튼의 기존 이벤트 바인딩 확인. 다중 클라이언트 및 화면 전환 테스트는 이번에 수행하지 않았습니다.

실행 도구는 `restyle_lobby.py`, 그래프 비교/PIE 시작은 `prepare_lobby_test.py`,
PIE 안에서 기능 확인은 `test_lobby_ui.py`입니다.
연결 방법은 `UNREAL_CONNECTION.md`를 참고합니다.

백업과 진단 자료: `LOL_UNREAL/Saved/DesignBackups/LobbyBefore_20260909/`.
복원 시 에디터를 닫고 백업의 두 uasset을 `Content/Lobby/`에 복사합니다.
최초 위젯 생성 시 UE 5.7의 GUID 복구 검사에서 디버거가 일시정지할 수 있으므로
자동 디자인 적용은 디버거 없이 실행합니다. 열린 미리보기의 Undo 참조 문제를 피하기 위해
자동 수정은 디자이너를 닫고 Undo 트랜잭션 없이 수행합니다.
