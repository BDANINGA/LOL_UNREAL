# 챔피언 선택 화면 변경

수정 에셋:
- `/Game/ChampionSelectMap/wbp_pick`
- `/Game/ChampionSelectMap/WBP_ChampSlot` (팀원 초상화 크기/간격)

남색 배경, 금색 윤곽선, 아군/상대 팀 패널, 상단 카운트다운, 정사각형 5×2 초상화,
한글 챔피언 이름, 호버/누름 스타일, 선택 확정 버튼을 적용했습니다.
1920×1080 기준 디자인을 ScaleBox로 비율 유지 축소/확대합니다.

기존 버튼 이름, 블루프린트 이벤트 그래프, 서버 RPC 및 타이머 연결을 유지했습니다.
밴 단계, 검색, 룬/소환사 주문 선택은 기존 게임에 없는 기능이라 이번 시각 변경에는 추가하지 않았습니다.
팀 슬롯 설명은 고정 표시이며 실제 선택 초상화는 기존 WBP_ChampSlot 로직이 갱신합니다.

## 검증

- 에디터 디자이너 및 실제 PIE 화면 확인.
- PIE에서 10개 버튼의 OnClicked 델리게이트를 발생시켜 각 ChampionID 매핑 검증.
- 선택 확정 OnClicked 후 준비 상태와 LockedChampion 검증.
- 팀 ID를 지정한 PIE 플레이어의 선택 초상화 표시 확인.
- 위젯 재컴파일 및 에셋 저장 완료.
- 실제 마우스 입력 자동화로는 선택 결과를 확인하지 못해, 입력 이벤트 경로는 델리게이트 실행으로 검증했습니다.
- 다중 클라이언트 네트워크 테스트는 수행하지 않았습니다.

기존 코드에서 트린다미어는 `EChampionID::Olaf` 값에 연결되어 있습니다.
게임 모드도 이 값을 트린다미어 클래스로 매핑하므로 이를 그대로 유지했습니다.

## 백업 및 재적용

원본 파일 및 점검 자료는 `LOL_UNREAL/Saved/DesignBackups/PickBefore_20260909/`에 있습니다.
원본으로 복원할 때는 에디터를 닫은 후 백업의 두 uasset을 Content/ChampionSelectMap에 복사합니다.

레이아웃 재적용 도구는 `restyle_pick.py`, 팀 초상화 크기 조정 도구는 `finalize_pick.py`입니다.
에디터 연결 도구를 통해 실행하며, 재적용 후에는 위젯을 컴파일하고 해당 에셋만 저장합니다.
미리보기 창을 닫고 적용하도록 구성했습니다. 열린 미리보기와 Undo 트랜잭션을 함께 갱신하면
Unreal 5.7의 World Leaks 오류가 발생할 수 있어, 자동 수정 스크립트는 Undo 트랜잭션을 사용하지 않습니다.
